Arty's STD LIB is a library containing multiple commonly used modules for other Arty's projects.
The module currently includes:
  ASHTP(Arty's secure HTTP transport protocol): a custom HTTP wrapper for use when TLS and HTTPS aren't available.\n
  Arty's Events Manager: allows events to be subscribed to and invoked from different threads and scripts.\n
  CAP(Command and Argument Parser): allows for definition of commands and their arguments and flags. \n
