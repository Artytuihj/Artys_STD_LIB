# Arty's STD LIB

A collection of commonly used modules shared across all of Arty's projects.

## Modules

| Module | Full name | What it does |
|--------|-----------|--------------|
| **ASHTP** | Arty's Secure HTTP Transport Protocol | Custom HTTP wrapper for environments where TLS and HTTPS aren't available |
| **Events Manager** | Arty's Events Manager | Subscribe to and invoke events across threads and scripts |
| **CAP** | Command and Argument Parser | Define commands along with their arguments and flags |

---

### ASHTP
Custom HTTP wrapper for use when TLS and HTTPS aren't available.

### Events Manager
Lets events be subscribed to and invoked from different threads and scripts.

### CAP
Lets you define commands and their arguments and flags.
